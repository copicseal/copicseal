# 04 — 导出系统

## 概述

导出系统将应用了模板的照片输出为图像文件，支持多格式、多尺寸、批量处理。

---

## 4.1 输出格式

| 格式 | 特点 | 质量设定 |
|------|------|----------|
| JPEG | 通用，体积小 | 质量 0–100%（默认 80%） |
| PNG | 无损，支持透明 | 无质量损失 |
| WebP | 现代格式，体积更小 | 质量可调 |

---

## 4.2 输出规格

用户可为每张照片配置多个输出规格，一次导出生成多个文件。

### 尺寸定义

| 参数 | 说明 |
|------|------|
| 宽度 × 高度 | 目标像素尺寸 |
| 缩放比例 | 额外缩放因子 |
| 原始尺寸 | 使用照片 EXIF 中的原始宽高 |

### 预设示例

| 预设名 | 格式 | 尺寸 | 质量 |
|--------|------|------|------|
| Instagram 帖子 | JPEG | 1080×1080 | 85% |
| Twitter 横图 | JPEG | 1200×675 | 85% |
| 原图尺寸 | PNG | 原始 | 100% |
| WebP 优化 | WebP | 原始 | 80% |

---

## 4.3 批量导出

### 流程

1. 用户确认导出规格（可多选）
2. 选择导出目录
3. 开始批量处理
4. 显示进度（当前文件 / 总文件数）
5. 可随时取消（当前照片处理完后停止）

### 进度显示

| 信息 | 说明 |
|------|------|
| 当前文件名 | 正在处理的照片 |
| 进度条 | 视觉反馈 |
| 计数 | "第 5 / 50 张" |
| 取消按钮 | 停止后续处理 |

### 文件命名

```
{原文件名}@{宽}x{高}.{格式}
```

示例：`DSC00123@1080x1080.jpg`

---

## 4.4 DPI 设置

导出时可指定 DPI（每英寸点数）：

- JPEG：写入 XResolution / YResolution 字段
- PNG：写入 PixelsPerUnitX / Y 字段
- 默认从原始照片 EXIF 读取 DPI

---

## 4.5 背景样式

导出时可为照片添加背景，有三种模式：

### 无背景

- 透明背景（仅 PNG 有效）
- 输出尺寸按照片比例自动计算

### 纯色背景

| 参数 | 说明 |
|------|------|
| 颜色 | 任意 RGBA 颜色 |
| 边距 | 上下左右间距 |

### 图片背景

| 参数 | 说明 |
|------|------|
| 背景图 | 自定义图片 URL |
| 模糊 | 0–1rem |
| 亮度 | 0–200% |
| 对比度 | 百分比 |
| 灰度 | 0–100% |
| 色相旋转 | 角度 |
| 反转 | 百分比 |
| 饱和度 | 百分比 |

支持区分明暗模式和横竖版的不同背景样式。
