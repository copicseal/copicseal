# 03 — 模板系统

## 概述

模板是预设的视觉设计方案，用户选择模板后照片会按模板样式渲染输出。模板决定了照片的边框、布局、元数据显示等视觉效果。

---

## 3.1 模板类型

### 内置模板

应用自带 6 套内置模板，无需网络即可使用：

| 示例 | 描述 |
|------|------|
| Default Template（白边） | 经典白色边框 + 相机参数 |
| 更多... | 不同风格的排版布局 |

### 远程模板

从官方注册表 `https://tpl.copicseal.com` 下载：

- 每个模板为一个独立文件，包含代码、样式、元数据
- 支持多个远程注册表
- 用户可选择性下载和启用

---

## 3.2 模板属性

每个模板定义一组可自定义的属性，例如：

| 属性 | 类型 | 说明 |
|------|------|------|
| 排版方向 | 自动/横版/竖版 | 自适应或强制方向 |
| 边距 | 数值（rem） | 边框与照片的间距 |
| 边框颜色 | 颜色 | 边框颜色 |
| 字体缩放 | 数值 | 文字大小缩放倍数 |
| 文字颜色 | 颜色 | 元数据文字颜色 |
| Logo 颜色 | 自动/自定义 | 相机品牌 Logo 着色方式 |
| 阴影 | 阴影配置 | 边框阴影效果 |
| 文字行 1 | 文本模板 | 第一行显示内容 |
| 文字行 2 | 文本模板 | 第二行显示内容 |

### 文本模板语法

模板属性中支持变量替换：

```
焦距：{FocalLength}  光圈：{FNumber}  快门：{ExposureTime}s  ISO{ISOSpeedRatings}
```

可用变量包括所有 EXIF 字段（见第 07 章）。

---

## 3.3 模板预设

用户可将当前的模板 + 属性 + 背景 + 字体组合保存为"预设"：

| 预设信息 | 说明 |
|----------|------|
| 预设名称 | 便于识别 |
| 模板 ID | 选中的模板 |
| 属性值 | 自定义的模板属性 |
| 背景设置 | 背景模式/颜色/图片/滤镜 |
| 字体 | 选择的字体族 |
| 描述 | 预设用途说明 |

示例：`微博晒图·白边` = 默认模板 + 特定颜色/间距/文字

---

## 3.4 模板注册表

### 官方注册表

- 名称："Copicseal 官方"
- 地址：`https://tpl.copicseal.com/manifest.json`

### 自定义注册表

用户可添加第三方注册表，项目结构：

```
manifest.json  →  模板列表（名称、版本、描述、作者、许可证）
template.json  →  单个模板（代码 + 样式 + 元数据 + 签名）
```

### 安全管理

- 远程模板使用 Ed25519 签名验证，防止代码篡改
- 签名校验通过后才能加载执行

---

## 3.5 模板启用管理

- 内置模板始终可用（不可完全禁用）
- 至少保留一个模板处于启用状态
- 用户可禁用不需要的远程模板以保持界面整洁
