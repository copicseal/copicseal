# 09 — 拼图系统

## 概述

拼图功能支持将多张照片拼接成一张大图，提供多种布局模板和自定义选项。

---

## 核心工作流

```
选择布局模板 → 上传照片 → 调整布局参数 → 预览 → 导出
```

---

## 支持的布局

### 双图布局

| 布局 | 图示 | 说明 |
|------|------|------|
| 左右并排 | `[A][B]` | 水平 1:1 或自定义比例 |
| 上下堆叠 | `[A]` `[B]` | 垂直 1:1 或自定义比例 |
| 一大一小 | `[  A  ][B]` | 主图 2/3 + 副图 1/3 |

### 三图布局

| 布局 | 图示 | 说明 |
|------|------|------|
| 水平三连 | `[A][B][C]` | 等宽 |
| 垂直三连 | `[A]` `[B]` `[C]` | 等高 |
| 上一大下两小 | `[   A   ]` `[B] [C]` | 上方全宽 |
| 左一大右两小 | `[A]` `[B]` / `[A]` `[C]` | 左侧全高 |
| 田字格缺一角 | `[A] [B]` `[C] [ ]` | 3/4 方格 |

### 四图及以上

| 布局 | 图示 | 说明 |
|------|------|------|
| 田字格 | `2×2` | 四方格 |
| 水平 N 连 | `[A][B][C][D]` | N 等分 |
| 网格 | `M×N` | 自定义行列 |
| 混合布局 | 预设模板 | 照片墙/瀑布流等 |

---

## 布局参数

每个布局支持以下可调参数：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| 间距 | 数值(px) | 8 | 照片之间的间距 |
| 背景色 | 颜色 | #ffffff | 间距区域的颜色 |
| 圆角 | 数值(px) | 0 | 每张照片的圆角 |
| 比例 | 自定义 | 等分 | 各照片所占宽度/高度比例 |
| 总画布宽度 | 数值(px) | 自动 | 最终大图宽度 |
| 总画布高度 | 数值(px) | 自动 | 最终大图高度 |
| 导出格式 | JPEG/PNG/WebP | JPEG | 输出格式 |

---

## 照片管理

### 导入

- 从当前会话中选择已有照片
- 拖入新照片到拼图区域
- 点击"添加"按钮选择文件

### 排序

- 拖拽调整照片在布局中的位置
- 点击交换两张照片的位置

### 单张照片调整

- 缩放/裁剪：拖动调整照片在格子内的显示区域
- 位置微调：上下左右平移
- 替换：点击替换为其他照片

---

## 布局模板预设

内置布局预设，用户选择后自动应用：

| 预设名称 | 布局 | 适用场景 |
|----------|------|----------|
| 横版双图 | 1:1 左右 | 对比照 |
| 三图横排 | 等分三列 | 序列展示 |
| 田字格 | 2×2 | 四图汇总 |
| 电影感上下 | 2.35:1 比例 | 截图拼接 |
| 小红书九宫格 | 3×3 | 社交分享 |

---

## 预览

- 实时预览拼图效果
- 支持缩放查看细节
- 修改参数即时刷新

---

## 导出

- 导出为单张大图（JPEG/PNG/WebP）
- DPI 设置
- 质量设置
- 批量导出多个拼图方案

---

## 存储

- 拼图预设保存到用户配置
- 支持预设的增删改查

## 技术实现要点

### 前端组件

```
CoCollageEditor（拼图编辑器）
├── CoCollageToolbar（工具栏：布局选择/参数调整）
├── CoCollageCanvas（画布：DOM 渲染拼图）
│   └── CoCollageSlot × N（每张照片的槽位）
└── CoCollagePhotoList（照片列表：拖拽排序）
```

### 渲染方式

- 使用 DOM + CSS Grid/Flexbox 渲染拼图画布
- 导出使用 snapdom 截图
- 与现有的 `--base-size` 系统兼容

### 数据模型

```typescript
interface CollageLayout {
  id: string;
  name: string;
  rows: number;
  cols: number;
  slots: CollageSlot[];
}

interface CollageSlot {
  row: number;
  col: number;
  rowSpan: number;
  colSpan: number;
}

interface CollageConfig {
  layoutId: string;
  gap: number;
  backgroundColor: string;
  borderRadius: number;
  slots: CollagePhotoSlot[];

interface CollagePhotoSlot {
  photoId: string;
  scale: number;

  offsetY: number;

```
