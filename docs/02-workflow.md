# 02 — 核心工作流

## 完整用户流程

```
导入照片 → 查看 EXIF → 选择模板 → 自定义样式 → 配置导出规格 → 导出
```

---

## 2.1 照片导入

### 支持的格式

| 格式 | 说明 |
|------|------|
| JPEG | 最常见，完全支持 |
| PNG | 支持透明背景 |
| HEIC | 自动转换为 PNG 后处理 |
| WebP | 现代格式支持 |

### 导入方式

- 拖拽照片到应用窗口
- 点击导入按钮选择文件
- 支持同时导入多张（批量模式）

### 导入后处理

1. 读取图片文件，生成预览 URL
2. 提取 EXIF 元数据
3. 提取色彩调色板（为后续功能预留）
4. HEIC 格式自动转换为 PNG 显示

---

## 2.2 照片管理

### 列表管理

| 操作 | 说明 |
|------|------|
| 查看列表 | 缩略图列表展示当前会话所有照片 |
| 切换照片 | 点击缩略图切换当前编辑的照片 |
| 删除照片 | 从会话中移除（不删除原文件） |
| 追加照片 | 向会话末尾继续添加照片 |

### 照片状态

每张照片独立维护以下状态：

- 原始文件与预览 URL
- EXIF 元数据
- 选中的模板及模板属性
- 导出规格配置
- 背景样式配置
- 字体选择

### 全局 vs 独立设置

- **全局设置**：修改后所有照片同步更新
- **独立设置**：可针对单张照片覆盖全局值

---

## 2.3 照片预览

### 实时预览

- 编辑区实时显示模板渲染后的最终效果
- 修改模板属性、背景、字体后即时刷新
- 预览区模拟最终输出效果

### 预览交互

- 支持缩放查看细节
- 切换横版/竖版预览模式
