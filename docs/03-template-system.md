# 03 — 模板系统

## 概述

Template 页面负责边框水印的完整生产流程，包括模板渲染、属性编辑、图片资产管理与批量导出。

路径：

```txt
/template
```

## 3.1 Workspace

Template 的 Workspace 渲染当前模板运行结果：

```tsx
<TemplateRuntime />
```

### Workspace 要求

- 显示当前模板的真实渲染结果
- 默认「适应」：无背景时照片加相框在预览区内等比占满；有背景时背景铺满整个预览区，照片加相框为预览区扣掉上下左右内边距后能放下的最大等比尺寸
- 支持缩放控制，提供 `Fit`、`50%`、`100%`、`200%`；`100%` 表示照片按原始像素宽度显示（1:1），其余档位以它为基准换算
- 缩放后画框大于预览区时由滚动条承载，不再压缩画面
- 导出结果直接来自当前渲染区域

## 3.2 Properties

Properties 采用可折叠分区组织，自上而下为：模板预设、模板（含全局字体）、模板参数、背景、导出、EXIF 信息。

### 模板预设

一条预设 = 模板 + 模板参数 + 背景 + 字体：把当前照片这套样式整体存下来，之后一键套用到其它照片。

```txt
模板预设
└─ 选择配置 ▾
   ├─ 存为新配置
   ├─ 微博图 · 白边
   └─ 深夜蓝
```

选中一条配置后可选四个动作：

| 动作 | 作用 |
|------|------|
| 覆盖配置 | 用当前照片的样式覆盖这条配置，名称与 id 不变 |
| 应用全部 | 把这条配置应用到所有图片 |
| 应用配置 | 只应用到当前图片 |
| 删除 | 删除这条配置 |

约束：

- 最多 10 条；名称 2 – 20 个字符，超出范围的输入不落库
- 预设不含导出档位：档位是「这批图怎么输出」，与「这套样式长什么样」是两件事，捆在一起会在套用样式时冲掉用户已经调好的输出尺寸（档位的默认值见 [04 导出系统](04-export-system.md)）
- 应用时模板、参数、背景与字体一次性写入：分开写会出现参数与新模板不匹配的中间态
- 应用后该照片即拥有自己的配置，不再跟随后续的默认值变化
- 预设持久化在配置的 `template_presets` 里，跨会话保留；照片与配置的绑定仍是会话级的
- 预设引用的模板在当前版本里已不存在时标记为「模板已失效」：不允许应用，但可以覆盖或删除
- 设置 → 边框水印 → 模板预设 里可以改名、上移下移、删除，并展开查看摘要

### 全局字体

- 属性面板「模板」分区顶部是全局字体下拉，`跟随模板默认` 表示不指定字体
- 字体作用在画布根上，模板里的 HTML 文案靠 CSS 继承拿到它
- 平铺水印的瓦片用**内联 `<svg>` + `<pattern>`** 平铺（不是 data URL 背景图）：内联 SVG 属于文档本身，字体直接继承画布根，预览与导出都能用上用户选的字体，也不需要把字体字节塞进瓦片
- 模板可以用 `fontDefaults` 声明自己的偏好字体栈（如胶片模板的等宽字）；用户选了字体则以用户选择为准
- 字体写入配置的 `fonts.default_font`：新导入与没单独调过的图片跟随它，模板预设可以给单张图片钉一个字体；从下拉里换字体时会解开当前照片被钉住的字体
- 设置 → 边框水印 → 默认项 与 设置 → 字体 共用同一份配置；模板页那处会顺手解开当前照片被钉住的字体（设置页没有「当前照片」的语境）
- 字体必须先「引入」才会出现在下拉里（设置 → 字体），三种来源横向并列：
  **Google Fonts**（内置常用字体清单，预览按需拉取，点「引入」才下载）、
  **本机字体**（引用系统字体，不复制文件）、**自定义导入**（文件复制进工作区 `Fonts/`）；
  每条都带实时预览。任意 URL / 自建索引作为后续扩展
- 导出的内联策略按格式分：ttf / otf / ttc 按用到的字形子集化；Google 给的 woff2 本身只有
  几十 KB，直接整份内联
- 本机字体只记引用；在线与导入的字体是工作区里真实存在的文件，预览与导出用同一份字节
- 按**族名去重**：同一个字体反复引入不会在工作区里堆出多份文件
- 每条都可以写**备注**（如「手写」），备注会显示在全局字体下拉里（「字体名 · 备注」），
  便于按用途挑字体而不必记住字体名
- 在线预览靠外部样式表（`fonts.googleapis.com`）加载，因此应用 CSP 需要放行
  `fonts.googleapis.com`（样式）与 `fonts.gstatic.com`（字体文件）
- 模板页的下拉只列出**已引入的字体**（设置 → 字体 里维护），避免在系统几百个字体里翻找；一条都没有时下拉里只有「跟随模板默认」，并提示去引入
- 收藏只是「下拉列出哪些」，不改变任何照片已经用的字体；当前字体即使不在收藏里也会补在下拉中，不会被清空

### Google Fonts 清单

「在线」来源用的是**内置清单**，不是运行时调接口：

- 数据来自 `https://fonts.google.com/metadata/fonts`（Google Fonts 官网自用的公开清单，无需
  API key），只保留带 `latin` 子集的族；中文 / 日文 / 韩文族被拆成上百个 `unicode-range`
  子集，CSS API 取不出单文件，因此不列在这里（这类字体走「自定义导入」）
- 生成为 `src/features/fonts/google-fonts.ts`（族名 + 分类，约 26 KB），运行时只做过滤，
  不发请求
- 字体文件在点「引入」时才按族名取 `https://fonts.googleapis.com/css2?family=…`，解析出
  文件地址再下载到工作区；预览同理但只加载当前列出的前若干个
- 重新生成：抓一次 metadata，把 `familyMetadataList` 里带 `latin` 的族按 `族名|分类代号`
  换行拼进 `RAW` 常量即可（分类代号 S 无衬线 / F 衬线 / D 展示 / H 手写 / M 等宽）

### Template Selector

模板选择器是一个单行下拉选择器，只占用一行高度，展开后展示当前内置模板：

```txt
Minimal
Film
白框
圆角
叠字
平铺水印
```

支持：

- 收藏：收藏的模板在下拉里置顶，当前模板可一键收藏或取消收藏
- 最近使用：最近切换过的模板排在其他未使用过的模板之前
- 快速定位：下拉支持键入首字母跳转到对应模板，不再单独占用搜索框

### Template Props

属性表单必须由 `propsSchema` 自动生成。

```txt
边框宽度
字体
字体大小
颜色
圆角
Logo
```

约束：

- 禁止手写模板专用表单
- 模板 UI 编辑项必须来源于 schema
- schema 同时定义默认值、类型、控件形态与校验规则

### 配置归属

模板、模板参数、背景与导出档位都属于**单张照片**，不是全列表共用一份：

- 编辑只作用于当前照片，切换照片时属性面板随之切换到该照片自己的配置
- 未编辑过的照片沿用框架默认配置（默认模板及其默认参数与背景）
- 「模板与参数」可以一键应用到其余照片；参数脱离所属模板没有意义，两者必须一起复制
- 「背景」单独提供一键应用，便于整批统一外框而保留各照片自己的模板
- 字体默认为全局值，模板预设可以给单张图片单独指定

### 尺寸口径

模板几何一律表达为渲染基准 `--co-base` 的倍数，数值参数的取值是「相对画布宽度的比例」。

从旧版模板迁移时按统一系数换算：旧运行时会把主图覆盖成 `4·aspect rem × 4rem`（主图高度恒为 `4rem`，3:2 时宽度为 `6rem`），折算到「主图占 0.9 画布宽度」后得出：

```txt
1 旧 rem ≈ 0.15 画布宽度比例
```

所有模板共用该系数，避免同一家族的字号、圆角、阴影出现量级差异。

- 旧版中本就是百分比语义的参数（如九宫格偏移）不受该系数影响，直接沿用百分数
- 旧版以画布高度为基准的值，需按目标宽高比另行换算

### 背景

背景是框架级能力，与模板自身的参数体系相互独立：模板有没有自己的边框，都不影响它。

```txt
无背景
纯色背景
照片模糊
```

字段：

```txt
背景模式
背景颜色
模糊强度
模糊图亮度
水平内边距
垂直内边距
```

纯色模式下，背景颜色字段下方提供从当前照片提取的**主题色盘**（前 5 色，按占比从高到低排列）：

```txt
照片主题色                   点击直接应用
● ● ● ● ●
```

- 点击色块即写入背景颜色，与当前颜色一致的色块带勾选标记
- 首次在某张照片上使用纯色背景时，颜色仍为默认值则默认取第一个主题色；用户自行改过颜色后不再覆盖
- 主题色是按图片缓存的派生数据，不写入配置；提取失败时只保留手动取色

约束：

- 默认值由当前模板提供，用户可以覆盖
- 切换模板时背景重置为该模板的默认值
- 字段按模式条件显示，不相关的字段不出现在面板上
- 内边距与模糊强度都是相对画框宽度的比例，不是像素值
- 背景是否启用会改变导出尺寸的语义，见 [04 导出系统](./04-export-system.md)
- 背景属于单张照片，可单独一键应用到其余照片

### Export

导出区块包含：

```txt
PNG
JPG
WEBP
质量
倍率
```

并提供：

- 导出
- 批量导出

导出档位同样属于单张照片：批量导出时每张图片按自己的档位输出，因此不同照片的档位数量与尺寸可以不同。

## 3.3 Assets

Template Assets 只属于 Template 页面。

内容：

```txt
图片缩略图列表
```

支持：

- 拖拽导入
- 粘贴导入
- 文件夹导入
- 排序
- 点击切换当前预览图片
- 逐张删除

## 3.4 模板运行系统

Template 页依赖独立的模板运行系统负责执行 React 模板。

### 职责

- 注册模板
- 加载模板元信息
- 解释 `propsSchema`
- 将 props 转化为可编辑 UI
- 管理模板生命周期
- 为导出提供稳定渲染目标

### 运行链路

```txt
Template Selector
↓
Template Registry
↓
propsSchema
↓
Template Runtime
↓
DOM
↓
Export Pipeline
```

## 3.5 数据边界

Template 与 Collage 必须独立。

Template 只共享以下能力：

- Export Pipeline
- Asset Infrastructure
- EXIF Infrastructure

Template 不共享以下内容：

- 编辑器状态
- 页面布局逻辑
- 属性面板状态
- 资产栏状态
