# 04 — 导出系统

## 概述

导出系统是 Template 与 Collage 共用的底层能力，用于将 Workspace 中的真实渲染结果输出为图片文件。

导出系统属于基础设施层，不属于任何单个 feature。渲染结果的编码与保存通过 Platform Contract 完成，以支持 Web 与 Tauri 两种运行环境。

---

## 4.1 设计目标

- 保证预览与导出结果一致
- 支持 Template 与 Collage 两类来源
- 支持单次导出与批量导出
- 支持稳定的进度、取消与错误反馈
- Web 与桌面端均可完成导出；根据平台能力选择目录保存或下载
- 导出尺寸由目标像素决定，不随窗口大小或设备像素比漂移

---

## 4.2 基础链路

```txt
React
↓
DOM
↓
渲染基准解算
↓
snapDOM
↓
Platform Export Service
├── encode PNG / JPG / WEBP
└── save to directory / download
```

### 说明

- 导出内容必须来自 Workspace 的真实渲染区
- 不允许维护一套与预览分离的隐藏导出模板
- 渲染稳定性由 `core/renderer` 负责
- 导出任务调度由 `core/scheduler` 负责
- 渲染基准的读写由导出服务通过适配器发起，DOM 由 Template 页面持有
- Platform Provider 负责格式编码和宿主相关的保存方式

---

## 4.3 输出档位

一次导出由一个或多个**输出档位**组成，每个档位独立描述一组尺寸与编码参数。

| 字段 | 说明 |
|------|------|
| `label` | 档位名称 |
| `format` | `PNG` / `JPG` / `WEBP` |
| `width` / `height` | 目标框尺寸（像素），两轴必填 |
| `scale` | 位图倍率 |
| `quality` | 编码质量，仅 JPG / WEBP 生效 |

约束：

- 档位数量至少为一，支持增删
- 各档位互不影响，独立解算、独立编码
- 目标尺寸缺值或非正数时不允许导出

---

## 4.4 渲染基准与尺寸解算

### 渲染基准

模板的几何必须全部表达为渲染基准的倍数。基准以 CSS 变量 `--co-base` 提供，其值即**画布宽度**：

```css
padding: calc(var(--co-base) * 0.05);
font-size: calc(var(--co-base) * 0.022);
```

约束：

- 模板内禁止出现 `px`、`rem`、`vh`、`vw` 等绝对单位与视口单位
- 允许 `em`、`%` 与无单位比值，它们随基准等比变化
- 模板参数的数值字段是无单位比例，不是像素值
- 不得通过 `html { font-size }` 或全局 `rem` 实现缩放

### 尺寸解算

导出时按档位的目标框反解基准，使画布在目标分辨率下**真实重排**，而不是把小尺寸结果放大：

```txt
以探针基准渲染
↓
测量画布布局尺寸
↓
按 contain 反解出命中目标框的基准
↓
应用基准并等待渲染稳定
↓
捕获
```

因为 `--co-base` 就是画布宽度，内容高宽比与基准无关，因此一次测量即可线性反解：

```txt
base = min(目标宽, 目标高 / 内容高宽比)
```

推导结果：主导轴精确命中设定值，另一轴按比例推导，不补边、不变形。测量必须使用布局尺寸（`offsetWidth` / `offsetHeight`），不得使用受变换影响的边界矩形。

### 背景与尺寸

渲染区由**画框**与**画布**两层组成：画框在最外层，承担背景填充与内边距；画布是模板本身，几何全部是 `--co-base` 的倍数。

背景模式直接决定目标框的角色：

| 背景 | 画框 | 画布 | 1280×720 + 方形画布的结果 |
|------|------|------|----------------------|
| 无背景 | 贴合画布 | 按 contain 命中目标框 | **720×720**（宽度按内容比例重算） |
| 纯色 / 照片模糊 | **精确等于目标框** | 在扣除内边距后的内容盒内 contain | **1280×720**（模板内嵌，其余由背景填充） |

约束：

- 内边距与模糊半径都写成画框宽度 `--co-frame` 的比例，不出现绝对单位
- 竖直内边距同样以画框宽度为基准，因此不依赖画框高度
- 模糊背景的外扩量取模糊半径的两倍，避免模糊之后画框边缘透出
- 画框属于框架层，其像素尺寸由解算逻辑直接设置，不受"模板内禁止绝对单位"的约束
- 导出前必须挂起预览自适应，避免其覆盖解算结果

### 倍率与像素比

- 输出倍率**只**来自档位的 `scale`，在解算尺寸之上做位图超采样
- 光栅化像素比固定为 `1`，避免设备像素比隐式放大结果
- 导出分辨率元数据（`dpi`）只写入 EXIF，不参与尺寸计算

---

## 4.5 Template 导出

Template 导出支持：

- 导出当前图片
- 批量导出当前资产列表
- 多张图片按当前模板配置连续输出
- 每个档位独立解算基准并输出
- 背景随当前模板与用户调整一同生效

批量导出时，当前模板、模板参数、背景与导出档位必须保持一致性。

导出前必须确保画布内的图片已加载完成，否则会按占位比例解算，导致尺寸偏差。

导出期间预览自适应必须挂起，避免其改写解算出的基准。

---

## 4.6 Collage 导出

Collage 导出支持：

- 导出当前拼图结果
- 保持与当前画布布局一致
- 复用统一输出档位结构，以单档形式提交

Collage 不参与模板的基准解算，其输出尺寸由画布自身的渲染尺寸与档位倍率决定。

---

## 4.7 批量导出状态

导出状态至少包括：

- 当前任务来源（Template / Collage）
- 当前文件名
- 已完成数量 / 总数量
- 当前档位
- 取消状态
- 错误信息

---

## 4.8 命名与目录

系统支持：

- 默认导出目录
- 用户选择导出目录
- 按来源与档位生成默认文件名

浏览器不支持目录选择或直接写入时，系统应以下载方式导出，并保留建议的文件名；不得将桌面目录选择器作为 Web 的前置条件。

多档导出时输出目录只询问一次，随后所有档位与所有图片直接落盘；单一档位沿用逐次保存对话框。

Template 命名：

```txt
{原始文件名}@{宽}x{高}.{格式}
```

同一批次内重名时追加序号。

Collage 命名：

```txt
collage-{时间戳}.{格式}
```
