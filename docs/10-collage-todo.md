## 2. 预览与画布

- [x] 保证 Workspace 为真实渲染区域

## 3. 布局库与工具栏

- [x] 布局库覆盖 1–20 张，按张数分组 + 线框缩略图
- [x] 「跳转到…」按张数快速定位
- [x] 网格 / 长图 / 自由三种模式切换
- [x] 工具栏：撤销 / 重做、选择 / 平移、自动填充、复位画面、导出
- [x] 画布缩放档位：适应 / 50% / 100% / 200%（与模板预览的档位一致）
- [x] 状态条：当前布局、未放入的素材数、画布比例

---

## 4. Assets 能力

- [x] 支持图片导入（按钮 + 拖入 + 粘贴）
- [x] 支持拖入拼图（指针事件自绘拖拽：桌面端原生拖放会截走 HTML5 拖放事件）
- [x] 支持单击空格填入当前素材
- [x] 支持双击素材放进第一个空格子
- [x] 支持在画布上拖动换位排序（网格与长图模式都可用，长图不受当前工具影响）
- [x] 预览「适应」按实测宽高比解算，长图整条能放进视口
- [x] 单格滚轮缩放（缩放工具下）
- [x] 切换布局自动把未放入的素材补进空位
- [x] 支持替换图片
- [x] 支持删除图片（并前移补洞）

---

## 5. Layout 面板

- [x] 支持间距（网格：格间合起来等于间距；长图：flex gap；自由模式不适用）
- [x] 支持边距（网格/自由：参与坐标换算；长图：容器 padding）——此前三种模式里都是失效的
- [x] 支持背景色
- [x] 支持圆角
- [x] 支持阴影
- [x] 画布比例预设（11 档）+ 自定义宽高
- [x] 长图方向 / 对齐 / 横轴尺寸

---

## 6. Selection 面板

- [x] 选中图片后显示属性（单格 / 画布分段）
- [x] 支持缩放
- [x] 支持位置调整 + 画布拖拽平移（1:1 跟手、方向跟随指针）
- [x] 支持旋转
- [x] 支持圆角（单格覆盖画布默认）
- [x] 支持水平 / 垂直翻转与一键复位
- [x] 支持单格填充方式：裁切填满 / 完整显示（面板内有裁切说明）
- [x] 快捷键：⌘/Ctrl+Z 撤销、⇧⌘/Ctrl+Z 重做、Delete 清空选中格、Esc 取消选中
- [x] 「补齐空位」不再清掉单格的取景与缩放（整块重排移到自由布局面板）

---

## 7. Export 面板

- [x] 支持 PNG
- [x] 支持 JPG（质量档位联动，落盘为真正的 JPEG）
- [x] 支持质量
- [x] 支持倍率（1x / 2x / 3x）
- [x] 目标宽高生效（导出的像素尺寸等于面板里的宽高；长图高度按内容）
- [x] 长图导出（竖向与横向都验过：主轴由内容决定，行/列宽高、边距、间距的像素值都对）
- [x] 文件名与落盘像素完全一致（含倍率与长图）
- [x] 导出期间冻结预览尺寸，避免适配器写进去的尺寸被 React 覆写
- [x] 锁定画布比例（改宽度自动推高度）
- [x] 常用尺寸复用「设置 → 导出 → 常用尺寸」同一份配置
- [x] 导出期间画布盖遮罩，避免尺寸跳变
- [x] 文件名按最终像素命名（含倍率），长图高度按画布比例推算
- [x] 空格子在导出时不印 `+` 与格子编号
- [x] 端到端校验：真实浏览器里导入真图 → 排版 → 导出，落盘 PNG 的像素与留白/间距均与设计值一致
- [x] 交互校验覆盖全部按钮与模式：拖入/换位/平移/滚轮/快捷键/长图对齐/自由复位与铺开/布局跳转/刷新持久化/导出遮罩
- [ ] 支持 WEBP（需要先让 Rust 侧承担编码，见 `shared/types/export.ts` 注释）
