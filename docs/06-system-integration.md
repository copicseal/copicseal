# 06 — 系统集成与存储

## 概述

应用与操作系统交互的能力，以及数据持久化策略。

---

## 6.1 文件系统操作

| 功能 | 说明 |
|------|------|
| 选择目录 | 调用系统原生目录选择器 |
| 打开文件夹 | 在系统资源管理器中打开指定路径 |
| 打开文件 | 用系统默认程序打开文件 |
| 检测路径类型 | 自动判断路径是文件还是文件夹 |

---

## 6.2 保存目录管理

### 默认目录

- 路径：`~/Documents/Copicseal`
- 首次启动自动创建
- 用户可随时更改

### 目录迁移

当用户更改保存目录时：

1. 将旧目录中所有内容移动到新目录
2. 如新目录已有同名文件则覆盖
3. 清理空的旧目录
4. 迁移失败时保留旧目录数据

### 目录结构

```
~/Documents/Copicseal/
├── templates/          # 下载的远程模板
│   ├── template-a.json
│   └── template-b.json
├── index.json          # 模板索引
└── exports/            # 用户指定的导出路径（可自定义）
```

---

## 6.3 配置持久化

所有用户配置持久化到本地文件，应用启动时自动加载：

| 数据类型 | 存储方式 |
|----------|----------|
| 应用配置 | JSON 文件（平台应用数据目录） |
| 设备 ID | UUID（首次生成后不变） |
| 模板 | JSON 文件（保存在用户文档目录） |
| 导出预设 | JSON（包含在应用配置中） |
| 模板预设 | JSON（包含在应用配置中） |

### 自动保存

配置变更后立即持久化，无需用户手动保存，应用崩溃不会丢失设置。

