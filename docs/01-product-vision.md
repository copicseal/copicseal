# 01 — 产品愿景与目标

## 产品定位

Copicseal 是一款**摄影后期批处理桌面工具**，为摄影师提供：

- 为照片添加**精美边框与元数据水印**
- 一键**多尺寸、多格式批量导出**
- 丰富的**模板系统**（内置 + 远程下载）
- 完整的 **EXIF 相机信息展示与编辑**

## 目标用户

- 摄影爱好者：想在社交平台分享带有相机参数水印的作品
- 专业摄影师：需要批量处理照片、统一视觉风格
- 摄影社区运营：需要为大量照片添加统一边框和信息

## 核心价值

| 能力 | 价值 |
|------|------|
| 相机信息可视化 | 自动读取 EXIF，格式化展示相机型号、参数，匹配品牌 Logo |
| 批量处理 | 一次导入多张照片，一键批量导出多种尺寸/格式 |
| 模板系统 | 内置精美模板，支持远程下载扩展，可自定义样式 |
| 多平台适配 | 同一张照片导出 Instagram、Twitter 等多种平台的适配尺寸 |

## 设计原则

1. **离线优先**：所有功能本地运行，无需网络（远程模板下载除外）
2. **数据安全**：用户的照片和配置仅存储在本地
3. **高性能**：批量处理不卡顿，实时预览流畅
4. **简洁直观**：降低学习成本，摄影师开箱即用
5. **可扩展**：模板系统支持社区贡献和远程更新
