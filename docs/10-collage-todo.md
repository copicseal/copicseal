# 10 — 拼图功能开发清单

> 基于 [09-拼图系统](./09-collage-system.md) 与 2026-06-08 最新需求补充
> 状态更新时间：2026-06-08

---

## 1. 需求梳理与基础设施

- [x] 对齐拼图功能最新需求与现有原型差距
- [x] 梳理可复用能力：图片导入、SnapDOM 导出、基础 UI 组件
- [x] 安装拼图专用依赖：`zustand`、`dnd-kit`、`react-rnd`、`framer-motion`
- [x] 建立独立的拼图模块目录结构

---

## 2. 图片管理

- [x] 支持上传多张图片
- [x] 支持拖拽上传
- [x] 支持批量上传
- [x] 支持替换图片
- [x] 支持删除图片
- [x] 支持图片重新排序
- [x] 支持图片交换位置

---

## 3. 拼图布局

- [x] 提供 1/2/3/4/5/6/9/12/16 张图片布局
- [x] 内置布局总数不少于 50 个
- [x] 布局结构支持持续扩展
- [x] 支持布局切换动画与预览

---

## 4. 单图编辑

- [x] 每个图片区域支持缩放
- [x] 每个图片区域支持平移
- [x] 每个图片区域支持旋转
- [x] 每个图片区域支持重置位置
- [x] 默认使用 Cover 模式填充区域

---

## 5. 画布与样式

- [x] 支持快捷比例：`1:1`、`16:9`、`9:16`、`4:3`、`3:4`、`16:10`
- [x] 支持自定义宽高比例
- [x] 支持背景颜色
- [x] 支持背景图片
- [x] 支持图片间距
- [x] 支持画布边距
- [x] 支持图片圆角
- [x] 调整后实时预览

---

## 6. 标注工具

- [x] 文字：内容、字号、颜色、拖拽、旋转
- [x] 箭头：长度、方向、颜色、粗细
- [x] 矩形：拖拽、缩放、边框颜色、边框粗细
- [x] 圆形：拖拽、缩放、边框颜色、边框粗细

---

## 7. 导出与历史记录

- [x] 支持 PNG 导出
- [x] 支持 JPG 导出
- [x] 支持标准 / 高清 / 超清质量档位
- [x] 导出结果与预览保持一致
- [x] 支持撤销
- [x] 支持重做
- [x] 记录所有核心编辑操作

## 8. 用户体验

- [x] 拖拽交互完善
- [x] 快捷键操作
